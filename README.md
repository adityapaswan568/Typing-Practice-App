# FlowType - Modern Typing Practice

FlowType is a sleek, modern web application designed to help users elevate their typing speed and accuracy. It features a clean user interface and provides real-time feedback on your typing performance.

**🚀 Live Demo:** [Play FlowType Here](https://adityapaswan568.github.io/Typing-Practice-App/)

## Features

- **Real-time Statistics:** Live tracking of your Words Per Minute (WPM), accuracy percentage, and elapsed time.
- **Dynamic Phrases:** Randomly selected texts covering various topics (technology, space, history, etc.) for each practice session.
- **Interactive Feedback:** Visual cues for correct and incorrect keystrokes as you type.
- **Results Summary:** A comprehensive modal at the end of each test displaying your final WPM, accuracy, time, and correct keystrokes.
- **Modern UI:** Built with a clean aesthetic using HTML, CSS, and Feather Icons.
- **Responsive Design:** Hidden input capture to ensure functionality across different devices and keyboard types.

## How to Run Locally

Since this is a static web application built with HTML, CSS, and Vanilla JavaScript, no build process or server is strictly required to run it locally.

1.  Clone this repository or download the source files.
2.  Navigate to the project directory.
3.  Open the `index.html` file in your preferred web browser.
    *   *Alternatively, if you have a local development server installed (like VS Code's "Live Server" extension, Python's `http.server`, or Node's `http-server`), you can serve the directory to view it on `localhost`.*

## Technologies Used

-   **HTML5:** Structure of the web page.
-   **CSS3:** Styling and modern design elements.
-   **JavaScript (Vanilla):** Core logic for typing test, timer, WPM calculation, and DOM manipulation.
-   **Feather Icons:** Minimalist icons used in the interface.

## How to Play

1.  When you load the page, a phrase will be displayed on the screen.
2.  Start typing the phrase. The timer will automatically begin as soon as you press the first key.
3.  Your current character will be highlighted. Correctly typed characters turn one color, while incorrect ones will be marked differently.
4.  Keep an eye on your live WPM and accuracy in the stats bar above.
5.  Once you finish typing the entire phrase, a results modal will appear showing your final statistics.
6.  Click "Play Again" or use the "Restart" button at any time to try a new phrase.
